# voice - the brand's own stream

Shaped empty with the template on 2026-11-05; the headings are the ones
`templates/voice.md` carries for every stream. Filled only by
`/corpus-update --apply`, tighten-only, from the brand's own briefs: published
copy first, designed copy second, and where the two disagree the file says so
instead of overwriting. A section stays empty until a brief evidences it.

Not written yet. Until this file carries a voice, the stream drafts nothing.

**The rule that binds every voice file.** Streams are isolated (plan v2,
decision 3): this voice never merges with another stream's in a single output,
never borrows its vocabulary, and names another stream only under a pair rule in
`streams.md`. If a line reads as two narrators, it fails. The writing skills
check every draft against this file before anything ships.
