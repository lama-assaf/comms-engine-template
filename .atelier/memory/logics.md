# logics - the argument structures, not the sentences

`voice.md` says how we sound. `glossary.md` says what words mean. **This file
holds the reusable shapes of argument**: the moves that make a claim land,
which survive being re-cut for X, LinkedIn, a deck or a regulator briefing.

A logic is portable in a way a line is not. When a draft feels flat, the problem
is usually that it asserts a conclusion without running one of these. The
`logics` column of `themes.md` names, per theme, which of these a post runs;
a logic that needs nothing shipped is the evergreen floor for a held theme.

Logics are extracted by `/corpus-update --apply` from the brand's own strategy
material and numbered `L1`, `L2`, ... in order of entry; a number is never
reused. Each entry carries the five fields below. `L1` is written as an
example of the form; replace its content with the brand's first logic and keep
the fields.

---

## L1 - the structural argument (example of the form)

**Shape:** the moves, as arrows: name the actors or facts the argument starts
from, then the step that turns them, then the conclusion the reader reaches on
their own. A shape has no brand in it; it is what survives translation to any
platform.

**Canonical run:** the one worked instance, quoted from the brand's material
where it exists, in two or three sentences. Here: name a fact nobody chose, a
policy somebody did, and show that only the first can be checked by a reader.

**Why it works:** what the shape does to the audience. Here: it blames no one,
so nobody has to concede error to agree, and it claims only what can be
checked, so a regulator can read it unedited.

**Reuse:** the questions this logic answers and the themes it serves. Here:
any "why should we believe you rather than the next vendor" question, and any
theme whose layer has not shipped, since the argument needs nothing shipped.

**Careful:** the failure mode. Here: the moment the argument names a villain
rather than a configuration, it collapses into a complaint; and the moment it
claims the policy as well as the fact, it is a claim ahead of shipping.
