# campaigns

One file per campaign, at `.atelier/memory/campaigns/<slug>.md`. A campaign
file is the single source of truth for that campaign's lifecycle: strategy,
engagement and retro skills all read and append to the same file.

## lifecycle sections

Each campaign file grows through four sections, in order:

1. **brief**: goal, audience, key message, platforms, the themes from
   `themes.md` it argues, constraints and banned topics.
2. **calendar**: dated slots, one line per post: platform, format, working
   title, theme, status. A held slot is marked as such.
3. **engager ledger**: appended as the campaign runs, and **patterns only**:
   counts, tiers and shapes of engagement per post (how many substantive
   replies, how many quote posts, which objection recurred). No handles, no
   names, nothing per person; that is the rule for every record the engine keeps.
4. **retro**: what worked, what did not, lessons worth promoting into
   `../lessons.md`, each with its evidence.

A thin section ("n/a for this campaign") beats a missing one.

## naming

Lowercase kebab-case, short: `q1-2027-launch`, `<theme>-evergreen-q2`. One
file per campaign.
